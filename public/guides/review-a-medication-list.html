How to review a medication list in DoseFolio

Search recorded medications, compare source directions and export your review progress without changing prescriptions or source status.

By the DoseFolio project · Published September 9, 2026 · Software guide

On this page

  1. Read the three counters correctly
  2. Find and inspect an entry
  3. Know what the export includes
  4. Use the checklist within its limits
  5. Questions about this guide

Read the three counters correctly

DoseFolio distinguishes the number of recorded medications, entries marked active by the source, and entries reviewed during the current session. Those counts answer different questions. A source status is part of the imported record; the reviewed count reflects clicks in this workspace.

Find and inspect an entry

Use “Find a medication” to filter by the displayed medication label. Clear the search when you want to see the full list again. Read the directions and frequency supplied with an entry. A missing instruction is shown as missing, rather than replaced with a guessed dose.

  1. Compare the label with the entry you meant to inspect.
  2. Read the recorded directions and the displayed source context.
  3. Mark the entry reviewed only after reading it.
  4. Keep unresolved questions for a pharmacist or clinician.

Know what the export includes

The text export includes the full imported medication list, each entry’s review flag, and its supplied dosage text or a missing-directions label. A search filter does not restrict the exported list. The file is a personal review aid; it is not a new prescription or a clinically reconciled medication list.

Use the checklist within its limits

DoseFolio displays allergies from the same authorized response for reference. It does not calculate drug interactions or advise changes to treatment. Review flags are temporary and do not write back to the source. The connected workflow remains subject to production activation.

Questions about this guide

Does searching change which medications are exported?

No. DoseFolio’s review export uses the complete returned medication list, with review flags, even when the screen is filtered.

Does “reviewed” mean safe to take?

No. It means you checked that entry in this session. The app does not assess medication safety.
